# 🤖 Telegram Бот Займов

Telegram бот для предоставления информации о займах в России и Казахстане.

## 📋 Возможности

- ✅ Выбор страны (Россия/Казахстан)
- ✅ Список микрозаймов с активными ссылками
- ✅ Удобный интерфейс с кнопками
- ✅ Поддержка прокси (опционально)
- ✅ Логирование действий пользователей

## 🚀 Установка и запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Получение токена бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен бота
4. Скопируйте токен

### 3. Настройка бота

Откройте файл `loan_bot.py` и замените `YOUR_BOT_TOKEN_HERE` на ваш токен:

```python
BOT_TOKEN = "1234567890:ABCdefGHIjklMNOpqrsTUVwxyz"  # Ваш токен
```

**Или** используйте переменную окружения:

```bash
export BOT_TOKEN="1234567890:ABCdefGHIjklMNOpqrsTUVwxyz"
```

### 4. Настройка прокси (опционально)

Если вам нужен прокси, в файле `loan_bot.py` установите:

```python
USE_PROXY = True  # Включить прокси
```

И укажите данные прокси:

```python
PROXY_HOST = "your-proxy-host"
PROXY_PORT = 8000
PROXY_USERNAME = "username"
PROXY_PASSWORD = "password"
PROXY_TYPE = "socks5"  # или "http"
```

### 5. Запуск бота

```bash
python loan_bot.py
```

Вы увидите сообщение:

```
2025-11-25 12:00:00 - __main__ - INFO - Starting bot without proxy
2025-11-25 12:00:00 - __main__ - INFO - Bot is starting...
```

## 📱 Использование

1. Найдите вашего бота в Telegram
2. Отправьте команду `/start`
3. Выберите страну (🇷🇺 Россия или 🇰🇿 Казахстан)
4. Получите список займов с активными ссылками
5. Нажмите "⬅️ Назад" для возврата к выбору страны

## 🔧 Структура кода

### Основные компоненты:

- **cmd_start()** - обработчик команды /start
- **callback_country_russia()** - обработчик выбора России
- **callback_country_kazakhstan()** - обработчик выбора Казахстана
- **callback_back_to_start()** - обработчик кнопки "Назад"
- **get_country_keyboard()** - создание клавиатуры выбора страны
- **get_back_keyboard()** - создание кнопки "Назад"

## 📊 Логирование

Бот логирует следующие события:

- Запуск бота
- Выполнение команды /start пользователем
- Выбор страны
- Возврат на главный экран
- Ошибки

Пример лога:

```
2025-11-25 12:05:30 - __main__ - INFO - User 123456789 (username) started the bot
2025-11-25 12:05:35 - __main__ - INFO - User 123456789 selected Russia
```

## ⚠️ Важные замечания

1. **Безопасность токена**: Никогда не публикуйте токен бота в открытом доступе
2. **Прокси**: Используйте прокси только при необходимости
3. **Ссылки**: Регулярно проверяйте актуальность ссылок на займы
4. **Законодательство**: Убедитесь, что ваша деятельность соответствует законам вашей страны

## 🔄 Обновление ссылок

Чтобы обновить ссылки на займы, отредактируйте переменные `RUSSIA_MESSAGE` и `KAZAKHSTAN_MESSAGE` в файле `loan_bot.py`.

## 🛠️ Troubleshooting

### Бот не запускается

1. Проверьте правильность токена
2. Убедитесь, что установлены все зависимости: `pip install -r requirements.txt`
3. Проверьте доступ к интернету (или прокси, если используется)

### Кнопки не работают

1. Убедитесь, что используете последнюю версию aiogram (3.x)
2. Проверьте логи на наличие ошибок

### Прокси не работает

1. Проверьте данные прокси (хост, порт, логин, пароль)
2. Убедитесь, что установлен `aiohttp-socks`: `pip install aiohttp-socks`
