📦 1. УСТАНОВКА ЗАВИСИМОСТЕЙ
   $ pip3 install -r requirements.txt

🔑 2. ПОЛУЧЕНИЕ ТОКЕНА
   - Откройте @BotFather в Telegram
   - Отправьте /newbot
   - Скопируйте токен

✏️  3. НАСТРОЙКА
   - Откройте: loan_bot.py
   - Замените: BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"
   - На: BOT_TOKEN = "ваш_токен"

🚀 4. ЗАПУСК
   Вариант 1: python3 loan_bot.py
   Вариант 2: ./start_bot.sh

✅ 5. ПРОВЕРКА
   - Найдите бота в Telegram
   - Отправьте /start
   - Выберите страну
   - Проверьте ссылки
