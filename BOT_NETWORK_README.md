## 📊 Как работает статистика

### Для каждого бота создается отдельный файл:

**Пример: `stats_data/bot_7920877021.json`**
```json
{
  "bot_id": "7920877021",
  "users": {
    "123456789": {
      "username": "user1",
      "first_seen": "2025-11-26T10:30:00",
      "last_action": "russia"
    }
  },
  "countries": {
    "russia": 156,
    "kazakhstan": 91
  }
}
```

### stats_bot агрегирует все файлы:

1. Читает все `bot_*.json` из `stats_data/`
2. Считает уникальных пользователей (один пользователь может быть в нескольких ботах)
3. Суммирует выбор стран
4. Вычисляет топ-5 самых активных ботов

## ⚙️ Настройка

### Добавление нового бота

1. Откройте `run_all_bots.py`
2. Добавьте в словарь `BOT_TOKENS`:
```python
BOT_TOKENS = {
    # ... существующие боты
    "NEW_BOT_ID": "NEW_BOT_ID:TOKEN",
}
```
3. Перезапустите `run_all_bots.py`

### Удаление бота

1. Удалите из `BOT_TOKENS` в `run_all_bots.py`
2. Удалите файл статистики: `stats_data/bot_ID.json`

## 🔧 Управление

### Запуск в фоне (Linux/macOS)


## 🚨 Troubleshooting

### Бот не запускается

**Ошибка:** `Token is invalid!`

**Решение:**
1. Проверьте токен в `run_all_bots.py`
2. Убедитесь, что токен активен в @BotFather

### Нет статистики

**Проблема:** `/stats` показывает "Нет данных"

**Решение:**
1. Проверьте, что `run_all_bots.py` запущен
2. Проверьте существование папки `stats_data/`
3. Убедитесь, что есть хотя бы один файл `bot_*.json`

### Боты зависают

**Решение:**
1. Остановите все процессы: `pkill -f run_all_bots`
2. Удалите старые данные: `rm -rf stats_data/*`
3. Перезапустите: `python3 run_all_bots.py`

### Много открытых соединений

**Проблема:** Ошибка "Too many open files"

**Решение:**
```bash
# Увеличьте лимит (Linux/macOS)
ulimit -n 4096

# Или добавьте в ~/.bashrc
echo "ulimit -n 4096" >> ~/.bashrc
```
