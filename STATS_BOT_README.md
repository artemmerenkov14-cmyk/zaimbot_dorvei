# 📊 Статистический Бот - Документация

## Описание

Отдельный бот для сбора и отображения статистики основного бота займов.

## Функциональность

### Команда /stats

При вводе команды `/stats` в админском чате бот отправляет подробную статистику:

```
📊 СТАТИСТИКА БОТА

👥 Всего пользователей: 150

🌍 Выбор стран:
🇷🇺 Россия: 95
🇰🇿 Казахстан: 55

📈 Процентное соотношение:
🇷🇺 Россия: 63.3%
🇰🇿 Казахстан: 36.7%
```

## Файлы

### stats_bot.py
Основной файл статистического бота.

### bot_stats.json
Автоматически создается основным ботом. Хранит:
- Список пользователей с их данными
- Счетчики выбора стран
- Временные метки действий

Пример структуры:
```json
{
  "users": {
    "123456789": {
      "username": "john_doe",
      "first_seen": "2025-11-26T10:30:00",
      "last_action": "russia"
    }
  },
  "countries": {
    "russia": 95,
    "kazakhstan": 55
  }
}
```

## Запуск

### Отдельно
```bash
python3 stats_bot.py
```

### Вместе с основным ботом
```bash
./start_all_bots.sh
```

Этот скрипт запускает оба бота одновременно:
- `loan_bot.py` - основной бот
- `stats_bot.py` - статистический бот

## Как работает

1. **Основной бот** (`loan_bot.py`) сохраняет данные в `bot_stats.json`:
   - Когда пользователь запускает бота (`/start`)
   - Когда пользователь выбирает страну

2. **Статистический бот** (`stats_bot.py`) читает `bot_stats.json`:
   - По команде `/stats` в админском чате
   - Формирует красивый отчет
   - Отправляет в тот же чат

## Безопасность

- ✅ Команда `/stats` работает только из админского чата
- ✅ Запросы из других чатов игнорируются
- ✅ Все действия логируются

Статистика обновляется в режиме реального времени:
- Каждое действие пользователя сразу сохраняется
- Команда `/stats` всегда показывает актуальные данные

## Troubleshooting

### Бот не отвечает на /stats

1. Проверьте, что команда отправлена в правильный чат (`-1003481337231`)
2. Убедитесь, что бот запущен: `ps aux | grep stats_bot`
3. Проверьте логи

### Статистика пустая

1. Убедитесь, что основной бот работает и создал файл `bot_stats.json`
2. Проверьте права на чтение файла
3. Запустите основной бот и сделайте несколько действий

### Ошибка "File not found"

Это нормально при первом запуске. Основной бот создаст файл при первом пользователе.
