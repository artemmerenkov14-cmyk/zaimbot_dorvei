## 🎯 Назначение файлов

### 🤖 Основные файлы

#### `loan_bot.py` (7.8 KB)
**Главный файл бота** - содержит всю логику работы:
- Обработчик команды `/start`
- Обработчики кнопок выбора страны
- Клавиатуры (inline кнопки)
- Тексты сообщений для России и Казахстана

**Запуск:**
```bash
python3 loan_bot.py
```

#### `config.py` (889 B)
Файл конфигурации для хранения настроек:
- Токен бота
- Настройки прокси
- Другие параметры

#### `start_bot.sh` (исполняемый скрипт)
Автоматический запуск с проверками:
- Проверяет наличие Python и pip
- Устанавливает зависимости если нужно
- Проверяет наличие токена
- Запускает бота

**Запуск:**
```bash
./start_bot.sh
```

### 📦 Зависимости

#### `requirements.txt` (74 B)
Список необходимых Python библиотек:
- `aiogram==3.15.0` - фреймворк для Telegram ботов
- `aiohttp==3.10.11` - асинхронные HTTP запросы

**Установка:**

## 🔑 Ключевые концепции

### Архитектура бота

```
Пользователь → Telegram API → aiogram → loan_bot.py
                                              ↓
                                        Обработчики:
                                        ├─ /start
                                        ├─ callback: country_russia
                                        ├─ callback: country_kazakhstan
                                        └─ callback: back_to_start
```

### Поток данных

```
1. Пользователь: /start
   ↓
2. Бот: Приветствие + кнопки выбора страны
   ↓
3. Пользователь: Нажимает кнопку (🇷🇺 или 🇰🇿)
   ↓
4. Бот: Список займов для выбранной страны
   ↓
5. Пользователь: Нажимает "Назад"
   ↓
6. Бот: Возврат к выбору страны (шаг 2)
```

## 🔧 Модификация бота

### Добавление новой страны

1. Добавьте кнопку в `get_country_keyboard()`
2. Создайте текст сообщения (например, `UKRAINE_MESSAGE`)
3. Создайте обработчик (например, `callback_country_ukraine`)
4. Зарегистрируйте обработчик в `main()`

### Изменение текстов

Все тексты находятся в начале `loan_bot.py`:
- `START_MESSAGE` - приветствие
- `RUSSIA_MESSAGE` - займы для России
- `KAZAKHSTAN_MESSAGE` - займы для Казахстана

### Добавление статистики

Можете добавить отправку статистики администратору:
```python
ADMIN_CHAT_ID = -1002688364224  # Ваш ID чата

async def send_stats(bot, user_id, action):
    await bot.send_message(
        ADMIN_CHAT_ID,
        f"User {user_id}: {action}"
    )
```

## 📞 Что делать если...

| Проблема | Решение |
|----------|---------|
| Бот не запускается | Проверьте токен и зависимости |
| Кнопки не работают | Обновите aiogram: `pip3 install --upgrade aiogram` |
| Ошибка "Invalid token" | Скопируйте токен заново от @BotFather |
| Прокси не работает | Проверьте данные прокси и установите `aiohttp-socks` |
