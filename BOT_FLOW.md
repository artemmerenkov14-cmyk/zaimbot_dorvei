## 🔧 Технические детали

### Обработчики (Handlers)

| Обработчик | Тип | Триггер | Действие |
|------------|-----|---------|----------|
| `cmd_start` | Message | `/start` | Показ приветствия + кнопки выбора страны |
| `callback_country_russia` | Callback | `country_russia` | Показ списка займов для России |
| `callback_country_kazakhstan` | Callback | `country_kazakhstan` | Показ списка займов для Казахстана |
| `callback_back_to_start` | Callback | `back_to_start` | Возврат к выбору страны |

### Клавиатуры (Keyboards)

#### `get_country_keyboard()`
```python
InlineKeyboardMarkup:
  Row 1: [🇷🇺 Россия] → callback_data="country_russia"
  Row 2: [🇰🇿 Казахстан] → callback_data="country_kazakhstan"
```

#### `get_back_keyboard()`
```python
InlineKeyboardMarkup:
  Row 1: [⬅️ Назад] → callback_data="back_to_start"
```

### Состояния бота

```
IDLE → /start → COUNTRY_SELECTION
         ↓
   [выбор страны]
         ↓
    LOANS_LIST → [⬅️ Назад] → COUNTRY_SELECTION
```
